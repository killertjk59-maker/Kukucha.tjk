# 🧸 Kukucha.tj — Интернет-магазини бозичаҳо ва либоси кӯдакона

Магазини пурраи онлайн ба услуби Wildberries: интихоби **миқдор ва андоза**, сабади харид, фармоиш, **админ-панели пурра**, режимҳои **торик/равшан** ва аниматсияҳо.

Дизайн аз рӯи логотипи бренди **Kukucha** (рангҳои карамелӣ/қаҳваранг дар заминаи кремӣ) сохта шудааст.

## ✨ Имкониятҳо

### Барои харидорон (ба монанди Wildberries)
- 🛒 **Интихоби миқдор ва андоза** — либос/пойафзол дорои андозаҳо (104/110/116..., 24-33, S/M/L) бо анбори алоҳидаи ҳар андоза
- 🔍 Ҷустуҷӯи зуд (бо ҳарфҳои тоҷикӣ ҳам кор мекунад), филтрҳо аз рӯи категория ва нарх, мураттабсозӣ
- 🛒 Сабади харид: зиёд/кам кардани миқдор, нест кардан, ҳисоби худкор
- 📦 Чек-аут: курьер ё гирифтан аз магазин, пардохти нақд/корти/терминал
- 📋 Пайгирии фармоиш: ҳолат (Нав → Тасдиқ → Дар роҳ → Расонида) бо таймлайн
- 👤 Ҳисоби шахсӣ: фармоишҳо, профил, ивази парол
- 🏬 Бақайдгирӣ бе телефон ҳам мумкин — танҳо логин + парол

### Админ-панел (`/admin`)
- 📊 Дашборд: даромад, фармоишҳо, диаграммаи фурӯш, огоҳиҳо дар бораи анбори кам
- 📦 Маҳсулотҳо: эҷод/таҳрир/нест, андозаҳо бо анбор, тахфифҳо, баҳо, «маъмул»
- 🗂 Категорияҳо: эҷод/таҳрир/нест бо иконка
- 📋 Фармоишҳо: рӯйхат, тафсилот, ивази ҳолат (new → confirmed → shipped → delivered / cancelled)
- 👥 Истифодабарандагон: нақшҳо, нест кардан
- 🛡 Ҳимоя аз зиёда аз анбор фурӯхтан — миқдор ба анбор маҳдуд мешавад

### Дизайн
- 🌙 **Режими торик ва равшан** — тугма дар сарлавҳа, дар хотира нигоҳ дошта мешавад (localStorage)
- 🎬 Аниматсияҳо: марки ҳаракаткунанда (marquee), пайдошавии пайдарпай (scroll reveal), hover-эффектҳо, ripple, поп-аниматсияи сабад, toast-паёмҳо, таймлайн, шумораҳои шинокунанда
- 📱 Пурра ба мобил мутобиқ (responsive)
- 🖼 10 расми генератсияшудаи маҳсулот + SVG-брендӣ барои боқимонда

## 🚀 Иҷро кардан

```bash
cd kukucha
npm install
node server.js
```

Сайт дар `http://localhost:3001` кушода мешавад.

## ☁️ Гузоштан дар Railway

1. Кодро ба GitHub гузоред (бидуни `node_modules` ва `data.db`)
2. Railway → **New Project** → **Deploy from GitHub repo** — худаш Node.js-ро мефаҳмад
3. **Settings → Generate Domain**
4. **Volume** илова кунед (Mount Path: `/data`) ва `DB_PATH = /data/data.db` — то маълумот дар deployment-ҳо гум нашавад
5. Replicas = 1 (сессияҳо дар хотира)
