# 🧸 kukucha.tj — Мағозаи онлайни кӯдакона

Мағозаи интернетии либос ва бозичаҳои кӯдакона бо Telegram-логин, чати 24/7, Telegram-бот ва админ-панел.

## ✅ Имкониятҳо

- 🔐 **Воридшавӣ тавассути Telegram** (ҳам барои харидорон ва ҳам админҳо) — Telegram Login Widget
- 💬 **Чати 24/7 бо менеҷер** — виджети чат дар кунҷи сайт; паёмҳо дар Telegram ба менеҷер меоянд, ҷавоб мустақиман ба сайт бармегардад (long-polling)
- 👥 **Якчанд админ/менеҷер** — ID-ҳои онҳоро бо вергул дар `ADMIN_TELEGRAM_IDS` ҷудо кунед
- 🛍️ **Витрина** — каталог бо филтрҳо (либос / бозича), ранг, размер
- 🛒 **Сабад** — дар `localStorage`
- 💳 **Пардохт** — маблағ ба `988757967` + боркунии чеки аксӣ
- 🤖 **Telegram-бот** — ҳар фармоиш + чек ба ҳамаи админҳо меояд; тугмаҳои «Тасдиқ / Рад»
- 🔔 **Огоҳинома ба харидор** — ҳангоми тасдиқ/ради фармоиш бевосита дар Telegram
- ⚙️ **Админ-панел** — идоракунии борҳо, фармоишҳо, сӯҳбатҳо, омор
- 📊 **Пайгирии фармоиш** бо код
- 💾 **PostgreSQL** — борҳо, корбарон, фармоишҳо, сӯҳбатҳо, сессияҳо

## ⚙️ Variables (Railway)

| Тағйирёбанда | Тавсиф |
|---|---|
| `BOT_TOKEN` | Токен аз @BotFather |
| `BOT_USERNAME` | Username-и бот (бе `@`), масалан `KukuchaShopBot` |
| `ADMIN_TELEGRAM_ID` | ID-и админи асосӣ (рақам) |
| `ADMIN_TELEGRAM_IDS` | ID-ҳои иловагии админ/менеҷерҳо бо вергул (ихтиёрӣ) |
| `SESSION_SECRET` | Рамзи дарози тасодуфӣ барои сессияҳо |
| `PAYMENT_PHONE` | `988757967` |
| `PAYMENT_OWNER` | `Душанбе Сити` |
| `NODE_ENV` | `production` |
| `DATABASE_URL` | Railway худаш мегузорад |

## 🚀 Қадамҳои омодасозии Telegram

1. **@BotFather → `/newbot`** — токен ва username-и ботро гиред
2. **Домени сайтро танзим кунед:**
   - Ба @BotFather равед → `/setdomain`
   - Ботро интихоб кунед
   - Домени сайти Railway-ро фиристед (масалан `kukucha.up.railway.app`)
   > ⚠️ Бе ин қадам тугмаи «Войти через Telegram» кор намекунад
3. **ID-и худро гиред:** ба бот `/start` ва `/myid` фиристед
4. ID-ро дар `ADMIN_TELEGRAM_ID` гузоред

## 🌐 Deploy ба Railway

```bash
# Локалӣ
npm install
cp .env.example .env
npm start

# GitHub
git init && git add . && git commit -m "kukucha.tj"
git branch -M main
git remote add origin https://github.com/USERNAME/kukucha.git
git push -u origin main
```

Дар Railway:
1. **New Project → Deploy from GitHub repo**
2. **New → Database → Add PostgreSQL**
3. Ҳамаи Variables-ро илова кунед (ҷадвали боло)
4. Deploy → интизор шавед, то сабз шавад

## 💬 Чӣ тавр чати 24/7 кор мекунад

1. Харидор тугмаи 💬-ро дар кунҷи рост зер мекунад
2. Агар логин набошад, Telegram Login Widget кушода мешавад
3. Харидор паём менависад → паём дар DB сабт мешавад ва ба **ҳамаи админҳо** дар Telegram меояд
4. Админ дар Telegram тугмаи **«💬 Ҷавоб»**-ро зер мекунад ва паём менависад
5. Паёми админ:
   - Дар DB сабт мешавад
   - Агар харидор ботро /start карда бошад, мустақиман ба Telegram-и ӯ меравад
   - Дар акси ҳол, харидор онро дар виджети чати сайт дар вақти воқеӣ мебинад (long-polling 25с)
6. `/chats` — 10 сӯҳбати охир; `/cancel` — бекор кардани ҳолати ҷавоб

## 🔄 Раванди харид

1. Воридшавӣ бо Telegram
2. Интихоби бор (размер + ранг) → сабад
3. Сабт кардан → ном/телефон/суроға (ном аз Telegram пур мешавад)
4. Пардохт ба `988757967` → боркунии чек
5. Фармоиш + чек ба Telegram-и ҳамаи админҳо меравад
6. Админ «Тасдиқ» ё «Рад»-ро зер мекунад → харидор дар Telegram огоҳ мешавад
7. Харидор метавонад бо код вазъро дар `/#/track` бубинад
